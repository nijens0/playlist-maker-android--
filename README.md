# playlist-maker-android--
Учебный проект по созданию мобильного приложения

PlaylistMaker
Приложение для поиска музыкальных треков и управления плейлистами.

Технический стек:
Минимальная версия Android (minSdk): 29
Java Development Kit (JDK): 11
Среда разработки: Android Studio (версия Ladybug или новее)

Сборка и запуск:
Склонируйте репозиторий на локальную машину.
Откройте проект в Android Studio.
Дождитесь завершения синхронизации проекта с файлами Gradle.
Выберите целевое устройство (эмулятор или физический девайс).
Нажмите кнопку Run или используйте сочетание клавиш Shift + F10.
